# bm-workspaces: a set of nip4 workspaces for technical imaging

This nip4 workspace is for working with technical images of museum
objects. It is useful for colour calibration, preparation of false-colour
images, and calibration of fluorescence images. 

### Acknowledgements

The development of these workspaces was funded by The British Museum under 
the EU CHARISMA programme. They were developed by Joanne Dyer, Giovanni Verri
and John Cupitt. 

### Installing nip4

nip4 is the GUI of the vips image processing system. 

For installation notes, see:

https://github.com/libvips/nip4#installing

### Loading the workspace

Start nip4 and drag `charisma-1-june-26.ws` into the main window, 
or alternatively use the Open button on the top-left of the main window.

We have a manual on how to use the workspace in this repository.

https://github.com/BritishMuseum/bm-charisma/charisma-manual.pdf
